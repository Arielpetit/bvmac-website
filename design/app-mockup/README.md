# BVMAC app mockup - 49 screens (390x844)
Each *.dc.html = one screen: HTML + inline CSS + a small JS class (state, handlers).
Custom tags: <x-dc>, <sc-for>, <sc-if>, {{holes}} filled by renderVals().
Links between screens: <a href="X.dc.html">. canvas.json = layout of the screens.
Palette: espresso #1c130b, gold #c9a23a, ivory #fbf9f5. Fonts: Fraunces + Geist.
